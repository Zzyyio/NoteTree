# Phase 2.5 Prompt：拖放文件管理与文件信息

完整阅读仓库根目录的 `PRODUCT.md`、`ARCHITECTURE.md`、`DESIGN.md`、`ROADMAP.md`、`TEST_PLAN.md` 和 `AGENTS.md`。检查当前 Git 状态，保留已有修改。开始前确认 Phase 2 的构建和测试为绿色；若不完整，只修复阻塞本阶段的缺陷。

本阶段只完善现有文件树的交互。复用 `WorkspaceFileSystem`、`FileTreeStore`、路径验证、系统废纸篓和现有 Undo 接入；不要平行创建第二套文件服务、Store 或权限模型。

## 目标

实现工作区内文件/文件夹的拖放移动，并完善文件树右键菜单中的重命名、复制、删除、文件属性/基本信息和新建 Markdown。

不要实现 Markdown 正文编辑、粘贴、外部文件导入、跨工作区复制、PDF/图片编辑或网络能力。

## 必须完成

### 1. 工作区内拖放移动

- 文件和文件夹可从文件树拖到另一个工作区内文件夹；拖放语义仅为“移动”，不复制。
- 拖放目标只能是当前工作区内、真实存在、非符号链接的文件夹。禁止拖到文件、工作区外路径、工作区根自身的非法位置，或源文件夹及其任何后代。
- 拖放时提供清晰的可接受/不可接受视觉反馈；拒绝时不得产生磁盘或树状态变化。
- 实际移动必须继续走现有 `WorkspaceFileSystem` actor 的受协调移动能力。操作成功后才刷新树、恢复合理的展开/选择状态，并注册 Undo；失败或冲突时保留原树状态并显示非模态错误。
- 不支持从 Finder 或其他应用拖入，也不支持把文件树内容拖到工作区外。不要猜测移动还是复制。

### 2. 右键菜单

按对象类型提供菜单；所有用户可见文本进入 String Catalog。

- 文件：打开（若已有路由）、重命名、复制、查看信息、在 Finder 中显示、移到废纸篓。
- 文件夹：新建 Markdown、重命名、复制、查看信息、在 Finder 中显示、移到废纸篓。
- 工作区根：新建 Markdown、查看信息、在 Finder 中显示；不得重命名、复制、移动或删除。
- 重命名保持行内交互：`Return` 确认、`Escape` 取消。空名称、路径分隔符、重复名称、权限失败和外部变更必须显示清晰错误，且不能静默覆盖。
- 删除必须调用系统废纸篓，保留恢复能力；不实现永久删除，也不添加“清空废纸篓”。
- “复制”明确为将选中项目的标准文件 URL 写入 macOS 系统剪贴板，供用户在 Finder 或其他支持文件 URL 的应用中粘贴。本阶段不实现文件树的“粘贴”或“复制到…”功能，避免未指定目标目录时的覆盖与冲突语义。

### 3. 文件属性与基本信息

- 右键“查看信息”打开轻量 popover 或 sheet，不修改文件内容。
- 显示：名称、类型、工作区内相对路径、大小、修改时间；文件夹还显示已加载或异步统计的直接子项数量。不得在日志中记录完整路径、bookmark data 或文件正文。
- 元数据读取在后台 actor/结构化并发中完成，View 保持 `@MainActor`。不存在、无权限或外部删除时提供可恢复错误状态。

### 4. 新建 Markdown

- 在根目录和文件夹右键菜单都能新建空白 Markdown；沿用现有安全创建、冲突保护、文件树刷新和 Undo 行为。
- 仅创建新文件，不实现正文编辑或自动保存。默认名称可以预填，但用户必须能够在提交前修改或取消。

## 不可违反的安全规则

- 每个公开文件操作都先标准化并验证路径仍位于已授权工作区 root 内；拒绝 `..`、符号链接、alias 和相似路径前缀逃逸。
- 不直接覆盖同名项目。移动、拖放、重命名和新建遇到冲突时停止并报错；不得自动改名或合并。
- 删除仅进入系统废纸篓；不得调用永久递归删除。
- 文件 I/O、目录枚举和文件夹计数不能阻塞主线程。使用 Swift 6 严格并发，不使用 `try!`、强制解包、`fatalError` 或 `@unchecked Sendable`。
- 不增加第三方依赖、后端、账户、遥测、广告或网络请求。

## 测试与验收

先为新增行为补充测试，再实现：

- 临时工作区测试：文件和文件夹拖放移动成功、同目录无操作、同名冲突、源/目标 root 边界、符号链接逃逸、移动到自身/后代、外部变更后的失败恢复。
- 测试右键对应的 Store/文件系统行为：行内重命名成功与取消、冲突不覆盖、复制写入文件 URL 剪贴板、系统废纸篓调用、根目录保护、新建 Markdown 和 Undo。
- 测试属性读取：文件、文件夹、缺失文件和权限失败；断言不会读取正文或写入文件。
- 使用注入工作区的最小 UI 测试验证菜单可访问、创建/重命名可操作，以及拖放可移动。不要自动确认系统授权面板；异步测试不得依赖任意 sleep。
- 运行完整构建与测试：

```bash
xcodebuild -project NoteTree.xcodeproj \
  -scheme NoteTree \
  -destination 'platform=macOS' \
  test
```
