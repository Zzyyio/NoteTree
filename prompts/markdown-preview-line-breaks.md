# Markdown 预览单换行

## 现象

编辑 Markdown 时按 Enter，源码已经换行，预览却把相邻行粘成一段。用户必须行尾两个空格或 `<br>` 才看得到换行，记笔记太重。

## 原因

CommonMark 里单个 `\n` 是软换行（渲染成空格），空行才是新段落，硬换行才要 `  \n` 或 `<br>`。预览用 `AttributedString(markdown:)`，走这套规则。编辑器按 Enter 只插入 `\n`，所以源码有换行、预览没有。

不要改成「按 Enter 自动写入两个空格或 `<br>`」。那会弄脏源码，代码块/列表/空行也容易写错。

## 可行方案

只改预览，不改源码、不拦截 Enter。

渲染前把正文里「非空行之间的单个换行」变成硬换行（行尾两个空格再 `\n`），再交给现有 `AttributedString`。空行仍是段落。围栏代码块（` ``` ` / ` ~~~ `）内部原样保留。

预览因此按笔记习惯分行；文件里仍是普通 `\n`，Git 和其他编辑器不受影响。不要引入第三方 Markdown 库，不要上块编辑器。
