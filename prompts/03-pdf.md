# Phase 4–5 Prompt：PDF 阅读、批注与安全保存

阅读所有根目录规范并遵守 `AGENTS.md`。确认此前 Phase 通过，只实现 `ROADMAP.md` Phase 4；阅读功能稳定并验收后再实现 Phase 5。

用 PDFKit 构建：

- `PDFView` 的 SwiftUI wrapper 和 `@MainActor PDFEditorController`。
- 连续/单页/双页模式、缩放、适合宽度、页码、目录、懒加载缩略图。
- 文本选择、复制和查找；无文本层时给出准确状态。
- 高亮、下划线、删除线、便签、自由文本、矩形/椭圆批注及页面旋转。
- 批注列表、选择、属性调整、删除和 undo/redo。
- dirty、手动 `⌘S`、另存副本与窗口关闭保护。
- 保存到同目录临时文件，再通过协调文件系统层原子替换；禁止直接覆盖唯一原件。
- 加密、权限受限、损坏或可能受数字签名影响的 PDF 默认只读并解释原因。

不要实现 OCR、签名编辑、页面合并/删除/重排或云服务。测试保存失败时原文件仍可由全新 `PDFDocument` 打开；保存成功后重新加载并验证批注。用大 PDF 检查主线程与内存，运行全量 build/test 后报告。
